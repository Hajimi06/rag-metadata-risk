# rag-metadata-risk

Audit pipeline for measuring metadata quality in RAG retrieval corpora.

## What this repo does

Compares document metadata from an aggregator against a gold standard, and measures
three kinds of metadata defects:

| Defect | Meaning | Example |
|--------|---------|---------|
| **Error** | wrong value / wrong attribution | wrong author, wrong venue, wrong trial link |
| **Missing** | field absent | NCT number not back-linked |
| **Representation inconsistency** | same entity, different form | transliteration, name order, journal rename |

## Data sources and gold standards

| Source | Gold standard | Join key |
|--------|---------------|----------|
| [OpenAlex](https://openalex.org) | [Crossref](https://www.crossref.org) | DOI |
| [ClinicalTrials.gov](https://clinicaltrials.gov) | [PubMed](https://pubmed.ncbi.nlm.nih.gov) | NCT |

## Setup

```bash
python -m venv .venv
source .venv/Scripts/activate          # Windows (bash)
pip install -r requirements.txt
```

> Note: on some networks the default PyPI is unreachable (SSL errors); use a mirror:
> `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

## Scripts

| Script | Purpose |
|--------|---------|
| `pull_sample.py` | Smoke test: pull 100 OpenAlex works, compare vs Crossref |
| `audit.py` | Stratified random audit (n=1000) of OpenAlex vs Crossref |
| `analyze_disagreement.py` | Normalization + matching layer (HTML decode, Cyrillic transliteration, name-order insensitive) |
| `audit_ct.py` | ClinicalTrials.gov vs PubMed NCT audit |
| `export_results.py` | Export audit results to Excel (three-type summary) |

## Results

- `results/step1_audit_summary.xlsx` — consolidated three-type summary (scholarly + clinical domains).
- `data/*/` — raw JSON (regenerated by the scripts; gitignored).
